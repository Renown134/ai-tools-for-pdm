# «Кто выгуливает Бориса» — учебный micro-MVP

Общая страница для вымышленной компании «Догяндекс»: сотрудники московского офиса записываются на прогулку с офисным псом Борисом и видят, кто кормил его последним.

Единственный источник требований — `spec.md`. Проект учебный, все имена и данные синтетические.

## Демо

Видео главного сценария (76 секунд): дата и пять слотов → запись сотрудника → отказ при попытке занять слот, занятый другим сотрудником во втором браузере → обновление страницы с сохранением записей → отметка кормления → узкий экран:

https://github.com/Renown134/ai-tools-for-pdm/raw/sprint-1/demo/boris-demo-sprint1.webm

## Что делает приложение

- Показывает текущую дату и ровно пять фиксированных слотов прогулок: `09:00`, `11:00`, `13:00`, `15:00`, `17:00`.
- Свободный слот можно занять: ввести ФИО и подтвердить запись.
- Занятый слот показывает ФИО записавшегося; повторная попытка занять его отклоняется сервером с понятным сообщением, первоначальная запись не меняется.
- Карточка «Последнее кормление»: время и ФИО сотрудника; новое кормление можно отметить по ФИО, карточка обновляется.
- Состояние хранится в настоящем SQLite-файле (`boris.db`) в папке проекта и сохраняется после обновления страницы и во втором браузере.
- Интерфейс читаем на широком и узком экране.

## Главный сценарий

1. Сотрудник открывает общую страницу и видит текущую дату и пять слотов.
2. Выбирает свободный слот, вводит ФИО и подтверждает запись.
3. Слот становится занятым, в нём отображается введённое ФИО.
4. Другой сотрудник при попытке занять тот же слот получает понятный отказ.
5. После обновления страницы или открытия во втором браузере состояние то же.

## Запуск

Требуется Node.js 22.5+ (используется встроенный модуль `node:sqlite`; проверено на Node v24.18.0). Внешних зависимостей нет.

```bash
npm install   # подготовка (зависимостей нет, проходит мгновенно)
npm start     # запуск сервера
```

После запуска страница открыта на `http://localhost:3000/`. Порт можно переопределить переменной окружения `PORT` (например, `PORT=3001 npm start`), это полезно, если порт 3000 занят оставшимся процессом.

При первом обращении приложение само создаёт файл `boris.db` (если его нет), создаёт таблицы по схеме из `spec.md` и инициализирует пять свободных слотов на текущую дату.

## Структура проекта

- `spec.md` — спецификация, единственный источник требований.
- `AGENTS.md` — правила работы с ИИ-агентом.
- `PLAN.md` — этапы, проверки и статусы работ.
- `README.md` — этот файл.
- `package.json` — npm-скрипты проекта (`start`).
- `server.js` — HTTP-сервер и работа с SQLite: раздача страницы, `GET /api/slots`, `POST /api/slots/book` (атомарная запись, конфликт → 409), `GET /api/feedings/latest`, `POST /api/feedings`.
- `public/index.html` — страница интерфейса (без фреймворков).
- `screenshots/` — по скриншоту на каждый из семи DoD.
- `demo/boris-demo-sprint1.webm` — видео-демо главного сценария (ссылка выше).
- `boris.db` — SQLite-база, создаётся автоматически при запуске.

## Границы решения

Учебный micro-MVP, а не внутренняя система «Догяндекса». Намеренно не входит: авторизация, роли, личный кабинет, отмена записи, календарь на неделю, история действий, уведомления, интеграции, внешние сервисы и API-ключи, деплой, масштабирование, production-grade эксплуатация.

## Данные

Все ФИО и значения синтетические, например «Анна Тестова» и «Илья Примеров». В проекте нет и не должно быть реальных ФИО, адресов, токенов и ключей.
